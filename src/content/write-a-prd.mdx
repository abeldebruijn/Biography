The `write-a-prd` skill is for turning an idea into a structured product requirements document. It combines clarification, codebase context, and feature decomposition so the resulting spec is grounded rather than abstract.

In practice, use it when a feature is still vague and needs to be turned into a document that engineering can actually implement. It is a good bridge between rough product intent and concrete delivery planning.

## Install
```
npx skills add mattpocock/skills@write-a-prd
```
