The `frontend-design` skill focuses on visual quality in frontend work. It pushes designs away from generic generated UI and toward more deliberate typography, spacing, motion, and composition.

In practice, use it when a landing page, interface, or component should feel intentional rather than merely functional. It is especially useful when building new presentation-heavy screens or refreshing an existing product surface.

## Install
```
npx skills add anthropics/skills@frontend-design
```
