The `convex` skill is a top-level guide for building with [Convex](https://www.convex.dev/). Rather than solving one narrow task, it helps route work toward the right Convex function, realtime, or agent-oriented pattern.

In practice, use it at the start of a Convex feature when you are unsure which Convex workflow fits best. It helps frame the problem before implementation details get locked in the wrong direction.

## Install

```
npx skills add waynesutton/convexskills
```
